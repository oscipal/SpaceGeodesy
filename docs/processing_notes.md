### Re-referencing

LiCSBAS steps 13 and 16 always re-reference `cum`/`vel` to an automatically chosen single pixel (lowest RMS of cum w.r.t. the median, `info/13ref.txt`), wherever it lies; the `120ref.txt` window only sets the reference during the inversion. The exported `cum.h5`/`cum_filt.h5` and `results/vel*` rasters are therefore re-referenced to the mean of the reference window above (exact: one constant per epoch). LiCSBAS's own choice is kept as `refarea_licsbas` in the h5 files.

- `016A_02504_162118/cum.h5`: LiCSBAS ref 472:473/38:39, window pixels valid in all epochs 25/25, velocity offset removed -9.79 mm/yr
- `016A_02504_162118/cum_filt.h5`: LiCSBAS ref 476:477/40:41, window pixels valid in all epochs 25/25, velocity offset removed -9.82 mm/yr
- `155D_02484_191814/cum.h5`: LiCSBAS ref 453:454/39:40, window pixels valid in all epochs 24/25, velocity offset removed 9.65 mm/yr
- `155D_02484_191814/cum_filt.h5`: LiCSBAS ref 478:479/43:44, window pixels valid in all epochs 25/25, velocity offset removed 7.33 mm/yr

Outputs: `results/licsbas/<frame>/` (cum.h5 unfiltered, cum_filt.h5 filtered, results/ rasters as float32 binaries on the grid in EQA.dem_par, info/), QC figures in `figures/qc/<frame>/`. Use cum.h5 (unfiltered) for event-related displacement; step 16 smooths sharp steps.
